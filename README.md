# rafscorp.github.io

Página de perfil pessoal, publicada via GitHub Pages em [rafscorp.github.io](https://rafscorp.github.io).

HTML, CSS e JavaScript puro — sem framework, sem build step. Só abrir o `index.html` já funciona localmente.

## Estrutura

- `index.html` — conteúdo da página (hero, sobre, projetos, skills, contato)
- `style.css` — estilos (tema escuro inspirado em terminal)
- `script.js` — efeito de digitação no hero e destaque do menu ativo ao rolar

01 · sobre

Aprendendo na prática, não decorando sintaxe

Comecei em C, direto no terminal, sem curso pronto — testando ideia por ideia até funcionar de verdade. De lá pra cá fui expandindo pra Python, Java e React, sempre com o mesmo princípio: construir algo que resolve um problema real (um caixa eletrônico, um sistema de estoque, um dashboard financeiro) em vez de replicar exercícios isolados. Prefiro entender o "porquê" de cada linha do que só fazer o código rodar.

Hoje já são 1,5 ano de C, 1 ano de React (com HTML/CSS/JS como base que veio junto no caminho) e 1 ano de Python, além de 6 meses de Java — tempo suficiente pra sair do "olá mundo" e entregar sistemas de verdade, inclusive pra empresas (ver seção abaixo).
